# Исследовательский анализ рынка общественного питания Москвы


**Цель:** определить перспективные направления для открытия нового заведения общественного питания в Москве.

**Задачи:**

- изучить данные о заведениях и ценах;
- провести предобработку;
- проанализировать категории, районы, рейтинги, ценовые категории и другие характеристики;
- сформулировать рекомендации для инвесторов.

**Данные:** 

`rest_info.csv` — информация о заведениях; `rest_price.csv` — данные о ценах и среднем чеке.

**Стек:** Python, pandas, matplotlib/seaborn, Jupyter Notebook.


### Конфиденциальность данных

Исходные базы данных не публикуются в репозитории в связи с соглашением о неразглашении (NDA). В репозитории представлена Jupyter Notebook с кодом анализа и описанием полученных результатов.
