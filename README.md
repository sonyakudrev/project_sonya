# Портфолио аналитика данных

В репозитории собраны проекты по анализу данных с использованием SQL и Python.

## Проекты

### 1. [Анализ рынка заведений общественного питания Москвы](01-moscow-restaurants-analysis/)

**Инструменты:** Python, Pandas, Matplotlib, Seaborn, Jupyter Notebook.

Анализ рынка заведений общественного питания Москвы: исследование структуры рынка, особенностей различных типов заведений и распределения объектов по районам.

[Открыть Jupyter Notebook](01-moscow-restaurants-analysis/moscow_food_service_market_analysis.ipynb)

### 2. [Анализ рынка недвижимости Санкт-Петербурга и Ленинградской области](02-real-estate-market-analysis/)

**Инструменты:** SQL, PostgreSQL.

Исследование сроков экспозиции объявлений, сезонности публикаций и снятия объявлений, а также различий между населёнными пунктами Ленинградской области.

В проекте представлены SQL-запросы и описание результатов анализа.
